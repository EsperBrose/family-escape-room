# 🗝️ Family Escape Room

A co-op escape room game for 2–20 players (ages 6+). Everyone plays on their own
phone, tablet or computer, and each screen shows different clues, so you have to
work together to escape.

**Play:** https://esperbrose.github.io/family-escape-room/

See [PLAN.md](PLAN.md) for the roadmap.

## Development
The game is a static site in `site/`. It deploys automatically to GitHub Pages
when changes merge to `main` (see `.github/workflows/deploy.yml`).
